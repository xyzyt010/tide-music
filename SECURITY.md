# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Tide Music, please do NOT create a public issue. Instead, report it privately to the repository owner or open a private security advisory on GitHub:

1. Navigate to the **Security** tab of the repository.
2. Click on **Report a vulnerability**.
3. Fill in the details, including reproduction steps and potential impact.

We will review the vulnerability and release a patch as quickly as possible.
